# Legacy API (deprecated)

This directory contains the **old GASdf API** (`/v1/health`, `/v1/tokens`, `/v1/quote`, `/v1/submit`).
It is based on an early version of Kora (circa December 2025) and is **not deployed**.

The current production surface is `relay-gateway/` (TypeScript, Kora integration).

Do not add new features here. New work goes in `relay-gateway/`.
